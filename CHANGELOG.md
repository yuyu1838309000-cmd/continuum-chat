# Changelog

## v0.1.0 — 2026-09-20

Initial public release.

- Flutter Android client with Chat, History, Memory, Tools, and Settings
- FastAPI Runtime and separate Memory service
- SQLite canonical conversation history and explicit Context Epochs
- Offline Mock Provider and configurable OpenAI-compatible provider endpoints
- Manual MCP tool discovery/invocation
- Provider input/output token usage analytics
- Loopback-safe defaults, bearer authentication for non-loopback binding, and privacy scanning
- Chinese and English documentation with sanitized reproducible demo screenshots

Current scope remains single-user, self-hosted, and reference-oriented. It does not include multi-user authorization, autonomous model tool execution, semantic/vector memory retrieval, or production deployment automation.
